# Security policy

The latest 2.x release is the supported version. Reproduce the problem on it before reporting.

## Reporting a vulnerability

Report it privately: on the repository's **Security** tab, choose **Report a vulnerability**
(GitHub private vulnerability reporting for `LaserLloyd/ThemeForge`). Do not open a public issue.

## Scope

In scope: the JavaScript runtime (`ui-theme/ui-theme.js`, `ui-components.js`), the `themeforge`
package (import name `forgeui`) including `python -m forgeui vendor`, and `ui-theme/update.py`.
